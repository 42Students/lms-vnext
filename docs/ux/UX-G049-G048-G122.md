## UX-G049 — Retired test-only Super Admin sign-in

Owned surfaces:
- src/app/e2e/superadmin-login/page.tsx
- src/app/e2e/superadmin-login/loading.tsx
- src/app/e2e/superadmin-login/error.tsx

Implemented source: The deprecated page has a full-viewport, responsive
guidance card, a visible secure sign-in destination and a safe home fallback.
It is explicitly noindex/nofollow/noarchive with no-referrer metadata.
The error screen has an accessible retry and safe sign-in route, and the
loading state identifies the legacy guidance correctly. The legacy phone
query is never printed. The existing development-only signed Super Admin
condition is unchanged. No session, OTP, role or membership can be minted
from this page, even if the old link includes a phone number. No provider
configuration was changed.

Proof gates: SSR/source tests for the negative authorization path; Chromium
390x844 and 1280x800 visits with a synthetic phone query, no query value
leak, safe links, noindex, no overflow, no uncaught page errors; scoped lint
and TypeScript. No production sign-in or real E2E seed flow implied.

## UX-G048 — Role-aware dashboard

Owned surfaces:
- src/app/(authenticated)/dashboard/page.tsx
- src/app/(authenticated)/dashboard/loading.tsx
- src/app/(authenticated)/dashboard/error.tsx

Implemented source: The authorized dashboard metric group now has an
accessible landmark and a responsive two/four-column layout. College
administrator shortcut actions use full-width mobile touch targets and
wrap on larger viewports. A dashboard-shaped metric skeleton replaces the
generic directory-only placeholder, retaining a bounded graceful loader.
The route-specific error fallback now permits leaving a broken dashboard
through the public home rather than looping back to that same dashboard.

Security invariants: no change to Super Admin no-college aggregation,
selected college scoping, the exact single active membership model, the
role-aware data-service calls, recruiter grants, learner placement access,
or denial propagation. Zero private metrics are disclosed from the public
page. Existing role service tests remain applicable.

Proof gates: lint/typecheck, scoped role/isolation source regression and
anonymous browser protection at 1280x800 + 390x844. Positive authenticated
role-specific browser flows remain dependent on provisioned test sessions
and are **not** implied by the anonymous guard test alone.

## UX-G122 — Tracker logs and reporter-owned issues

Owned surfaces:
- src/app/(authenticated)/tracker/logs/page.tsx
- src/app/(authenticated)/tracker/logs/loading.tsx
- src/app/(authenticated)/tracker/logs/error.tsx
- src/app/(authenticated)/tracker/mine/page.tsx
- src/app/(authenticated)/tracker/mine/[publicId]/page.tsx

Implemented source: The log loading title now correctly reads "Logs"
rather than "Known Errors", with an access-check status sentence.
Log anchor navigation has 44px touch-friendly targets. My Reports gains
an explicit retry when reporting is offline, a count for populated result
sets and an accessible list label. Individual report details gain
noindex/nofollow metadata, a retry link when the module is unavailable
and mobile-sized retry links on optional screenshot/activity failures.

Security invariants: the log explorer still requires an active named
unscoped Super Admin and audits access; the old shared password never
grants access. Reporter list/detail still requires an active context and
scoped reporter service; guessed IDs are schema-validated, canonicalized
and checked for ownership independently on issue, history and media
reads. The access gate and private file-scan policy are untouched.

Proof gates: scoped tests for invalid ID, disabled actor, missing report,
unavailable DB and feature-off recovery, private actor data boundaries,
anonymous browser access at desktop and mobile, scoped lint and TypeScript.
