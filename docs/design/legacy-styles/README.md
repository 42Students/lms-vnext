# Old LMS style sources (copied verbatim from 42LMS-FRONTEND/lms2-fe/src/styles, 2026-10-19)
Reference only, do not import. Files are flattened as `<folder>__<name>`. `components___variables.scss` holds the canonical tokens; `_button`, `_form`, `_dropdown`, `_header`, `_common`, `_antddesign`, `_listing-page-header`, `_learn-layout`, `_notification-drawer`, `pages___login`, `pages___admin-*` show how the old LMS skins shared elements (buttons, inputs, selects, dropdowns, tables via antd overrides, headers, drawers, login). Port the VALUES (colours, radii, borders, shadows, font sizes and weights, spacing, hover/focus states, transitions) into vNext's shared UI kit and global tokens. The TPO sidebar/top bar rules are in `../old-lms-shell.css` (extracted from the running app).
