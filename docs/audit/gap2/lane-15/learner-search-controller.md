# U013 — LearnerSearchController: scoped learner search and auxiliary APIs

## Source closure and mapping
Legacy controller `docs/legacy-source/backend/src/main/java/com/_42students/lms/search/learners/LearnerSearchController.java` (378 lines), cache `docs/legacy-source/backend/src/main/java/com/_42students/lms/search/learners/LearnerSearchCache.java`, DTO `docs/legacy-source/backend/src/main/java/com/_42students/lms/search/learners/LearnerSearchDTO.java`, access/teaching assignment dependencies named in imports. New nearest directory: `src/modules/people/college-role-directory-service.ts` with query `src/modules/people/college-role-directory-model.ts`; super-admin `src/modules/people/admin-user-directory-service.ts`/`src/modules/people/admin-user-directory-model.ts`; pages `src/app/(authenticated)/college/people/manage/page.tsx`/`src/app/(authenticated)/admin/people/directory/page.tsx`. Legacy dedicated /api/v2/learners endpoints do not map one-for-one: people directory is a different role-centric route. This audit distinguishes backend search contract from additional vNext people-management UI and flags old faculty class-scoped access. Legacy methods for program/college/popular/category/exists use requireSearchRole(...,null) and therefore deny faculty even though the class search permits assigned faculty; this unusual internal behavior is recorded precisely, not assumed permissive.
