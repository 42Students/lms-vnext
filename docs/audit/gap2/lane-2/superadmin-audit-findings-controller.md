## Unit summary

- **Rows:** 72. **Verdicts:** GAP 48; MISSING 12; MATCH 4; UNKNOWN 2; EXTRA 6. **Severity:** P1 29; P2 27; P3 16.
- **Top gap 1 (P1):** GitHub-backed importer and secure manual/scheduled sync are absent in vNext; neither `GET /sync`, `POST /sync` nor tamper/deletion handling exists. Restore credential-scoped GitHub App reader, scheduler lock, immutable import ledger, validated importer, rich sync state, and user-visible Sync now action (`LG:25-32`, `LI:64-75`, `LI:102-135`, `NP:114-124`, `NS:133-154`).
- **Top gap 2 (P1):** vNext schema drops legacy finding provenance and event/file metadata (environment, reported severity, affected roles, found-by session, source commit, event actor/type/commits/source), making faithful diagnostics impossible. Add columns, indexes, migrations and importer mapping (`LI:179-213`, `LI:253-284`, `NX:9-68`).
- **Top gap 3 (P1):** Server filtering and workflow differ: legacy severity-prioritized ordering, multi-area exact choices, comments up to 4000, assignees up to 100, legacy repo whitelist and status transition rules do not match vNext (`LS:51-68`, `LS:133-193`, `NP:78-105`, `NT:7-22`, `NV:4-15`).
