## Critical semantic decisions
**Deleted is not Archived.** Legacy exposes an admin recoverable-delete list, uses soft-deletion and restoration from a template; its own modal warns that edits to tasks, sprints and resources are unrecoverable. VNext archive retains those edits and the project remains available for review. The two workflows should not be merged or relabeled without an explicit owner decision. Legacy allows mentorless restores with `BLOCKED` warning; vNext restore is denied without a primary active mentor. Historic IDs and isDeleted→ARCHIVED migration require an explicit map.
