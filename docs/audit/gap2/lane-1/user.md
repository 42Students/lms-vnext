# U021 — User identity entity and legacy registration

Static audit 2026-10-21, no tests/CI. Unlike the unused LoginUser model, `User` **has real consumers**: `UserDao`, `UserServiceImpl` and `POST /users/register`, plus Spring `UserDetailsService`. The legacy registration path hashes password using BCrypt but also **grants USER and ADMIN roles to every registrant unconditionally**; it returns full `User` entity with password field not annotated JsonIgnore. This unsafe access-control and serialization behaviour must NOT be cloned. vNext uses a canonical account, phone/email OTP and explicit college/platform roles. The deprecated schema fields still need migration/disposition evidence and runtime acceptance.
