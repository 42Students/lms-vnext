# U029 — Company applicant share public page

Static audit 2026-10-21; no source edits/tests/CI. Legacy company share is a token+one-time-code page with optional code email delivery, a watermark-protected Ant Design applicant Table (25/page), selected columns, CSV download and ZIP resumes. vNext strengthens proof/session checks, uses server pagination, current shortlist filters and durable transaction audit. But it **removes email-code resend, ZIP and resume links**, changes raw UG percentage to a privacy band, and changes copy, sorting, list columns, watermark and empty placeholders. These are functional as well as pixel-level differences.
