# U019 — MobileLoginAttempt and OTP attempt lifecycle

Static code audit, 2026-10-21; no source modifications, tests or CI. This legacy entity is actively created/queried by PublicMobileAuthController and a repository with atomic five-guess reservation; MySQL schema includes `verification_attempts` missing from the Java model declaration. The old path stores **plaintext** SMS/email OTP and grants a 90-second replay window for already-used SMS challenges; vNext has a unified, HMAC-only OTP attempt with atomic one-time consume, bounded retries and contact/IP rate limits. Preserve deliberate security improvements instead of copying dangerous storage.
