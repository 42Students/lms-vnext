# L12-U013 — NotificationSearchController (v2)

Static audit 2026-10-21, no code/tests/CI execution. Legacy `GET /api/v2/notifications/search` searches title/message from a startup in-memory cache, permits global superadmin search or class/course-scoped search with access checks, hides future/other-learner items, exposes superadmin-only stats and manual cache refresh. vNext has per-user notification inbox, unread filtering and cursor pagination. It is safer and more scalable, but is **not the same global/class/course text-search endpoint**. In particular, do not mistake the vNext self-inbox as a feature-equivalent backend search API.
