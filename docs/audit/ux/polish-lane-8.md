# Lane 8 — UI/UX polish evidence

## Surface 1 — `src/app/(authenticated)/college/academics/page.tsx`

**Problems found (12):** (1) Four creation forms were simultaneously exposed above every academic list; (2) creation choice had no single focus; (3) forms crowded 375px width and split attention at 768px; (4) their submit controls lived in four large blocks; (5) the directory navigation competed with the page's first action; (6–9) periods, programs, cohorts, and sections each showed an oversized repeated generic empty panel with no next step; (10) program Edit/Archive controls competed in each row; (11) planned cohort Edit/Activate/Archive controls cluttered rows; (12) section Open/Edit/Archive wrapped beside each other, particularly on phones.

**What changed:** The creation area is now a small responsive 2-column (375px) / 4-column (768px+) row of the **existing** Create period/program/cohort/section labels. It renders only the selected form visibly while preserving all four form elements, input ids, values, validators, POST endpoints, and toast/refresh paths; selection reports aria-expanded/aria-controls and success closes the form. The page heading retains one h1 and original subtitle; the existing "Open Programs directory" link now sits next to its related Programs heading, with the same href. Empty tables keep "No records to show.", keep their status live region, and add the appropriate existing "Create..." label linking to the creation selector instead of occupying a large standalone empty-state panel. For this page alone, Program, planned Cohort and Section row actions use the existing accessible Dropdown/Menu components; edits, Archive, Activate and Open routes and callbacks remain available, and all other callers continue to use the original action rows. The Section Open link stays visible and first. Mobile dropdowns use the existing bottom-sheet behaviour with 44px targets; desktop trigger height is 36px to match row controls. Spacing uses the existing legacy 8/12/16/24px scale, colours, fonts, and radii unchanged.

**States / breakpoints inspected in source:** filled rows for all four tables, empty lists, pending create actions, create-error toast, success/reset, planned/active/closed lifecycle menus and confirmation dialogs, disabled Archive when linked records exist, keyboard focus/Escape via shared Dropdown/Menu/Dialog, 375px and 768px responsive classes. Existing route `loading.tsx` (directory skeleton and delayed retry), `error.tsx` (clear message and Retry), nearest `college/layout.tsx` (role guard and group tabs), and inherited `college/not-found.tsx` were reviewed; no changes necessary. No route-level template or not-found file exists in this folder. This is a static source review, not a browser screenshot parity claim. No CI executed.

**Files changed:** `src/app/(authenticated)/college/academics/page.tsx`; `src/components/academics/academics-create-panel.tsx`; `src/components/academics/academics-overview.tsx`; `src/components/academics/academics-actions.tsx`. Queue ticked in `docs/orchestrator/queues/clone/lane-8-polish.md`.
