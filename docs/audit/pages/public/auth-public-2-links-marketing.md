## 4. Intentional differences (approved or clear improvements in vNext)
- Company share uses a single high-entropy token checked in one transaction with a row lock, database-clock expiry, revocation and an audit row that must succeed (failure denies the page); no-index, no-referrer, no-store headers; search by name and server pagination; mobile card layout; per-link audit viewable by the placement cell. Treat as improvements; the open point is the disclosure and code decision.
- Recruiter invite: first open is recorded by a separate same-origin POST so the GET stays read-only (mail scanners cannot mark an invite opened); `/hr-invite/[token]` alias redirect; token shape validated before any lookup.
- Unsubscribe and join links use one generic unavailable page and strict readiness gates (see `campaigns-public.md`).
- Marketing pages: owner has not decided whether they are in scope; nothing was built, none audited in depth.
