## 4. Intentional differences

- Third optional module `Electives` in Feature Controls and Module Access (default ON); legacy catalogue is Projects and Placements only (`BE ModuleFeatureCatalog` DEFAULT_OFF = placements). No decision file found (UNCONFIRMED); matrix shows it as a first-class module.
- Feature Controls matrix is a richer finder (module / stored value / lock / presence / last-updated / search-in filters, sorting, CSV export) than legacy's name search; keep.
- Module-level audit history has CSV export and cursor paging; student history is separate.
- Module Access directory lets Super Admin browse any college without first scoping the header.
- Settings page adds `Origin` (stored vs default vs fixed) and `Source file or table` columns, an SMS source-template catalogue and an authentication posture checklist; none exist in legacy. Whether the read-only stance is intended is a decision to record (gap 33).
- Placements membership-level rules are shown read-only because the resolver ignores them; legacy hides student-level Placements controls behind `Placement cell decides`.
- Defaults match legacy (Projects ON, Placements OFF).
