## 4. Intentional differences
- Course / Offering / Section Delivery / Teaching Assignment model (`New Course Offering`, `Add Section Delivery`, `Assign Course Faculty`) replaces legacy per-course class mapping; courses are department-owned catalogue entries and teaching happens through offerings (`admin-course-create-panel.tsx:268-365`).
- Archive instead of delete for courses, lessons and offerings; history preserved; blocked by active children.
- Content directories deliberately omit file downloads, signed URLs and meeting links ("No file downloads or private meeting links are exposed."), and course thumbnails are staged until storage is provisioned.
- Rich HTML introduction is sanitised/escaped (`admin-course-display-editor.tsx:174`); per-version optimistic concurrency on the display editor.
- Quiz results release and assignment submission files go through audited services rather than direct admin endpoints.
