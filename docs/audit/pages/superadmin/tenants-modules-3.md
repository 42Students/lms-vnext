## 4. Intentional differences

- Activity Log: grouped related events with a count, a per-event detail page with redacted metadata, a College select, actor name / free-text / event type / subject filters, and a server-side CSV export that honours every filter (legacy exports only the loaded rows). Keep.
- Audit Findings access: vNext requires a Super Admin session; the legacy password-only `TrackerLogsAccessGate` is not replicated (security-sensitive; owner decision not found, UNCONFIRMED).
- Announcements: vNext adds scheduling, soft-delete + restore, audience types beyond placement cells, filters, CSV export, and an explicit review dialog with `Consent and publish` / consent checkbox on edit (`requiresPublicationConsent`, `src/modules/announcements/super-admin-publish-consent-model.ts`). The legacy flow sends immediately with no consent step. Treat as an added control; confirm with owner whether to keep the extra step.
- Verification drawer shows submitted vs previously verified values side by side and opens documents through a private signed route; legacy highlights changed values inline. Equivalent.
- Inbound mail: recipient-inbox filter, IST timestamps and the explicit "storage not registered" state (not a zero result).
