## 1. Legacy behaviour

### 1.0 Shared shell and conventions (all ten tabs)
- Every page is a thin wrapper (e.g. `P/departments.js:1-32`): when no college is selected in the header scope it renders ONLY a warning alert "Select a college to continue" / "Choose a college in the header above to see its <x>." (no tab strip). With a college selected it renders `SuperAdminGroupShell groupKey="academic"` (`C/admin/SuperAdminGroupShell.jsx:14-34`): `PageShell` titled "Academic Setup" with a tab strip of 10 tabs (`common/navGroupDefinitions.js:4-17`) and, for the first six tabs only, an `AdminWorkflowGuide` banner "Academic setup · Step N of 6: <tab>" with `Previous: <tab>` / `Next: <tab>` buttons (`C/admin/AdminWorkflowGuide.jsx:7-31`; steps = departments, programs, semesters, semester-courses, batches, classes).
- Every page body is `<h1 class="admin-list-page__title">` (+ optional subtitle) then a two-column layout: left card "Create New X" form, right card "Existing X" with `AdminTableToolbar` (debounced search 220 ms, "Clear search", "N of M results", Export CSV, Refresh; `C/admin/AdminTableToolbar.js:6-77`), AntD `Table` size small, `scroll x max-content`, default 10 rows with size changer and "a-b of N" total.
- Edit is a modal ("Save Changes"/"Cancel", `maskClosable=false`); closing a dirty modal asks "Discard ... changes?" (`Modal.confirm`, OK "Discard changes"). Delete is a `Popconfirm`; a failed delete leaves a closable red alert "X was not deleted" with a `Retry delete` button. Create/edit failures show a closable alert "X was not created/updated" and server field errors are mapped onto fields (`utils/formErrors`).
- Loading uses `TableSkeleton`/`RefreshStatus ("Refreshing x…")`; load failures show a warning (stale data kept) or error alert with `Retry`.

## 4. Intentional differences (vNext better or deliberately different)
- Archive instead of hard delete for departments, programs, halls (history kept; `department-actions.tsx`, `academics-actions.tsx`). Legacy hard-deletes after dependency checks.
- Program carries a required `code`; duration stored as terms (2 per year). Legacy has name + duration_years only.
- `/admin/academics` overview adds periods (calendar windows), program/cohort/section lifecycle, section roster/schedule workspace and recurring preview/execute; legacy has no "academic period" object (semesters are program terms).
- CSV exports neutralise spreadsheet formulas, include a BOM and IST timestamps (`department-directory.ts:40-60`, `super-admin-scoped-csv-model.ts`).
- Scope is enforced server-side per request (`requireSuperAdminSelectedCollege`) and invalid filter input renders a recoverable ErrorState with "Clear filters".
- Lecture-hall dialog shows "Upcoming classes" and blocks archive when classes exist; restore action; availability page.
- Attendance grid uses one Export CSV and an explicit correction window text from policy (`admin-attendance-workspace.tsx:292,687`).
