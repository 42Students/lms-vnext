## 4. Intentional differences (vNext better than, or approved departure from, legacy)
- Delivery-scoped routes (`/teacher/courses/{deliveryUuid}`) and per-Section isolation; shared Offering content is visible and read-only (`faculty-course-workspace.tsx` L424-L428). Legacy mixed shared and class content in one list.
- Course list adds `Academic period` and `Teaching role` filters, server pagination, learning-path status badge, per-card counters (`faculty-course-list.tsx`).
- Draft -> Publish -> Archive lifecycle for faculty content (legacy: immediate, soft delete). Content order editor, video thumbnails, video replacement, video processing states, `Hide from learners` toggle for video, signed preview.
- Live sessions can be edited and cancelled and are checked for overlapping Section schedule events (legacy: delete only) (`faculty-live-mutation-service.ts` L105-L115).
- Students: roster CSV, pagination, per-student detail, section switcher, reports hub; Discussions: moderation history, participation page, reply-to-message.
- Course tab order already matches legacy (Overview, Blueprint, Attendance, Discussions, Students).
