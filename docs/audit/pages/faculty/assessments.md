## 4. Intentional differences (vNext better than, or approved departure from, legacy)
- Section-scoped assessments with optimistic concurrency (`expectedUpdatedAt`), explicit Draft/Publish/Close/Archive lifecycle, archive instead of hard delete, and copy-to-new-draft for quizzes.
- Quiz builder extras: question search/invalid-only filter, move/insert/duplicate/paste choices, question CSV import, draft review summary (`faculty-choice-quiz-builder.tsx`, `faculty-quiz-question-editor.tsx`).
- Grading extras: written feedback, regrade explanation requirement, submission filters All/Pending/Graded/Late, pagination, file review with private file access, publish control separate from grading (owner may keep or collapse to legacy one-click, see FAC-assessments-06).
- Reports: CSV exports (attempted/not attempted, question accuracy), individual attempts view, assessment results overview (`/teacher/results`).
- Quiz results release is tied to quiz state CLOSED and recorded as an audited activity event (but see FAC-assessments-05).
