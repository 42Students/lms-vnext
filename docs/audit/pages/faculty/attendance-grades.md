### 1.4 Grades and marks (faculty)
- There is NO faculty gradebook or marks sheet in legacy. Marks exist only as: assignment points per submission (grading modal and reports, see `assessments.md`), quiz scores (submissions modal), and the home-tab `PerformanceCard` (distribution of assignment averages). The only gradebook code is admin analytics (`FE:data/admin/analytics-student/studentsGradeBook/index.js`). Learners see grades only after publish. Therefore "grade book/marks" parity items are limited to assignment and quiz marking (covered in `assessments.md`) and the Overview PerformanceCard/AtRisk card (covered in `courses.md`).

## 4. Intentional differences (vNext better than, or approved departure from, legacy)
- Atomic attendance save with optimistic concurrency, audit metadata (`correction`, `movedToAbsent`, `movedToPresent`, reason), college-configurable correction window and eligibility threshold, per-learner drill-in, month PDF, threshold breakdown.
- Learner attendance is never inferred as present: unmarked and upcoming sessions are excluded from percentages (matches the legacy LRN-AT-01 fix).
- Session reschedule for own unmarked sessions and overlap protection per Section; deep-link `?sessionId=` into Mark mode.
- Read-only published gradebook with CSV, learner score breakdown, section reports hub, assessment health, results overview, response follow-ups (no legacy equivalent).
