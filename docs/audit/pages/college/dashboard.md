### 1.2 "At a glance" strip (`AtAGlance.js`)
- Section H2 `At a glance`; four cards `Students`, `Faculty`, `Courses`, `Active drives` (L54-L59) from `GET /api/v1/admin/college-summary?collegeId=` (`LBE/controller/AdminCollegeSummaryController.java:59-105`): student count includes learners linked via class (`findLearnersByCollegeIdIncludingViaClass`), faculty count, non-deleted college courses, active drives (`jobRepository.countActiveByCollegeId`). - Values that cannot be resolved render `—`, never 0 (L81-L85). Loading is a skeleton per card. Whole-call failure with nothing loaded: Alert `Couldn't load college summary` / `The rest of the dashboard is still available.` with a `Retry` button (L67-L70); failure after a good load: warning `Summary refresh failed` / `Showing the last successful college totals.` plus a small `Retry` (L65,72-73).

### 1.3 "Today" attention board (`AttentionBoard.js`, `GET /api/v1/admin/college-dashboard?collegeId=`, `LBE/controller/AdminCollegeDashboardController.java`)
- H2 `Today`, a `Refresh` text button (L224-L226), an `aria-label="Needs attention"` section. Each section of the response fails independently (`section(...)` wrapper, controller L114).
- Today strip (L233-L243): `N class(es) scheduled today`, `N held so far`, `N with attendance taken` (highlighted warning when held > marked). Failure text `Today's classes couldn't be loaded.`
- Six cards in a responsive grid (xs 24, lg 12, xl 8), each with a count chip, a list of the first 8 rows (`LIST_LIMIT = 8`, controller L47) and `and N more` when the count exceeds the rows shown (L147-L160):
  1. `Attendance not taken`: sessions held in the last 7 days with no attendance marked; row `{course or title} · {class}` + `{ddd D MMM, h:mm A} · {faculty | no faculty set}`; empty `Every class held in the last 7 days has attendance.`; footer link `Open attendance` (L247-L257).
  2. `Under {threshold}% attendance` (threshold from the tenant attendance policy, default 75, controller L89-L103): learners under the threshold over the last 30 days counting marked sessions only; row `{name} · {roll number}` + red `{percent}%` tag + `{class} · {attended} of {n session(s)}`; empty `No student is under {threshold}% in the last 30 days.`; footer `Last 30 days, marked sessions only · Attendance` (L261-L273).
  3. `Waiting to be graded`: assignment submissions without a grade, grouped by course (`{course}` / `{n submission(s)} · oldest {D MMM}`), footer `Oldest from {D MMM YYYY} · Assignments`; empty `No assignment submission is waiting for a grade.` (L277-L287).
  4. `Courses with no teacher`: current-semester courses with no faculty for a section; row `{course}` / `{class} · Semester {n}`; footer `Students see these with nobody behind them · Faculty assignment`; empty `Every current-semester course has a teacher for every section.` (L291-L301).
  5. `Setup gaps`: link rows `N active batch(es) with no classes`, `N section(s) with no students`, `N student(s) not in any class`, `N course(s) with no lessons`; empty `Batches, sections, students and courses are all connected.` (L305-L316).
  6. `Quizzes closing this week`: next 7 days, row `{quiz title}` / `{course} · {class}` with tooltip `Only {class}` or `All sections taking the course`, `closes {ddd D MMM, h:mm A}`; empty `No quiz closes in the next 7 days.`; footer `Quizzes` (L320-L335).
- Card states: loading skeleton; failed `Couldn't load this. Refresh to try again.`; clear (green check + the empty text above). Board-level: failure with no data `Couldn't load today's overview.` + `Retry`; failure after a load `Refresh failed. Showing the last overview loaded for this college.`; everything clear `Nothing needs you right now.` (L199-L207, L227-L231, L337-L339).
- Counts are plain SQL COUNT queries scoped to the college, excluding deleted classes and suspended learners (`LBE/.../AdminCollegeDashboardController.java:50-58`).

### 1.5 Setup guide (`AdminDashboardView.js:64-74`, `SetupGuide.js`, `config.js:185-245`)
- A collapsed antd `Collapse` titled `Setting up a new college? Step-by-step setup guide` containing H2 `Setup Guide (Follow in Order)` and the intro `If you're setting up the LMS for the first time, follow these phases in order. Each phase depends on the previous one being completed.`
- Five numbered phases and 14 steps (steps renumbered sequentially): 1 `Structure`: Create Departments (Academic departments); 2 `Courses`: Create Courses (Add the subjects you teach (needs a department)), Add Lessons (Create lessons for courses), Add Lesson Content (Videos, resources and live classes); 3 `Academic Structure`: Set up Programs (Degree programs (B.Tech, MBA)), Create Semesters (Semesters within programs), Map courses to semesters (Which courses each semester teaches), Create Batches (Year batches (2024-2028)), Create Classes (Sections within each batch (e.g. CSE - A)); 4 `People`: Add Faculty (Teaching staff accounts), Assign Faculty (Who teaches which course for which section), Add Students (Student accounts, placed in a section); 5 `Lecture Halls & Jobs (Optional)`: Add Lecture Halls (Rooms used in the timetable), Jobs & Placements (Post and manage job openings). Each step is a keyboard-operable card with title, description, number and arrow; the aria label is `{title} — {desc}`.

### 1.6 Responsive, keyboard

## 4. Intentional differences

- vNext counts come from registered persisted records (memberships, enrollments) rather than legacy join heuristics; the plain "zero vs unavailable" distinction is kept in the model (`college-dashboard-cards-model.ts:34-38`), which matches the legacy `—` rule in spirit.
- Extra `Edit college`, `Contacts`, `Announcements`, `Verification`, `Branding` actions and the Code/City/State/Country card are vNext improvements (self-service college profile and quick routes); keep them but they must not replace the legacy blocks (COL-dashboard-11).
- Empty-record prompts (`Check empty record sets`) are a vNext addition, harmless once the `Setup gaps` card exists.
