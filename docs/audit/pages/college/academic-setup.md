## 4. Intentional differences

- Hard delete is replaced by archive/restore with dependency guards and activity events across departments, programs, classes, halls, electives and batches (data safety; decision records in the vNext module comments). The wording gap is COL-academic-setup-18/19/38; behaviour stays.
- Batches and classes are tied to an academic-period model (start period, expected end, section code) instead of free-text academic years; this is a schema decision of vNext (`docs/decisions`), only the missing legacy capabilities in COL-academic-setup-27/30 are gaps.
- Recurring schedule has a preview step with conflict preview before commit (improvement); only the missing `Course` field and all-or-none behaviour are gaps.
- Lecture hall availability page with booking and cancellation, hall `Upcoming classes` column, `Archived programs` restore section, activity events for every write, optimistic-version stamps and capped CSV downloads are improvements over legacy.
- Stored `Total credits` on a semester is a deliberate vNext extension but conflicts with the legacy derived-credits rule (COL-academic-setup-25): decide whether to hide the manual field.
