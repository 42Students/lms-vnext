### 1.3 Video (uploaded) (`syllabus/video.js`, `components/Global/video/video.js`)

- Below the player (learners): `ContentProgressBadge` with `Completed | In progress | Not started` and `NN% watched`, plus a thin progress bar (`ContentProgressBadge.jsx:5-78`).

## 2. vNext behaviour

### 2.0 Data and routing
- Page `V/app/(authenticated)/learn/courses/[deliveryId]/[...courseTab]/page.tsx:232-242` renders `LearnerCourseWorkspace` with `filter`, `lesson`, `content` search params. Data: `getLearnerCourseWorkspace` (`V/modules/courses/learner-course-service.ts`): published learning path -> `ACTIVE` lessons -> `PUBLISHED` contents whose `deliveryId` is null or this delivery, joined with the learner's progress row, assignments (+ submission row, grade only if published), quizzes (+ attempt counts). ## 4. Intentional differences (vNext improvements)
- Private signed playback for lesson videos with a short-lived grant renewed before expiry, preserved seek position, one auto-retry and `Retry video`; progress saved with `keepalive` on page hide (legacy used the stored public URL, so the object was reachable by anyone with the link, see the legacy comments in `LessonContentController.java:642-652`).
- Server-enforced timed completion (never client-asserted, 90 % of the authored duration), idempotent manual completion with a single activity event; live sessions can only be marked after they ended.
- Private, scanned assignment file uploads: staged files (up to 10 x 50 MiB), status badges, cancel, confirmation checkbox, one-shot signed downloads; legacy relied on public object URLs.
- Item dialogs are native `<dialog>` (focus containment, Escape) mounted on demand; deep links highlight the target; invalid `?filter=` is explained; mobile `Jump to lesson` list; per-filter counts.
- HTTPS-only authored links, unsafe link warnings; published-grade masking (a grade appears only after it is published, `Submitted. Grade is not published yet.`).
- Past-semester courses keep the Learning Path readable with write controls removed (`Past semester · quiz attempts are read only`, progress read only).
