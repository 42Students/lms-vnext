## 4. Intentional differences (vNext improvements or approved deviations)
- Assignments overview adds search, state filter with counts, sort, quick views, "Clear assessment filters", a live "Showing a–b of n" summary, full-page detail route with a course chooser for assignments present in several deliveries, and the published grade + written faculty feedback (legacy learner drawer shows only the card chip `Graded · x/y`). (`V/components/courses/learner-assessment-overview.tsx:241-321`; `.../[assignmentId]/page.tsx:64-90`)
- Final-submission confirmation (`window.confirm`, "You cannot replace it after submission") and `Submitting…`/disabled controls during flight; submission is immutable, matching legacy ("Already submitted for this assignment"). vNext links must be https without credentials and <= 2048 chars (legacy accepted http:// and no client check). (`assignment-submission-control.tsx:63-76`; `learner-assignment-link-model.ts`)
- File uploads: virus-scan metadata, per-submission receipts, up to 10 files with explicit allow-list, private bucket and signed open links (legacy: single receipt per file, block-list). Narrower type list is recorded as gap -07, not as an approval.
- Quiz history page with all attempts, per-question awards and "withheld until published" semantics; question set immutable after publish (no mid-attempt 409), advisory-lock race-safe attempt numbering, answer snapshots; session draft autosave is scoped by delivery+quiz and refuses to write when the loaded quiz no longer matches; deadline countdown warning in the last 10 minutes; `Go to first unanswered` and `Clear this answer`; unanswered questions are explicit instead of silently skipped (see gap -22 for the decision).
- Class Schedule: uses section deliveries so elective-group classes are included (legacy queried the home class only); shows faculty name and location (legacy DTO never carried them, so its popovers/strip showed none); session search, section filter, kind filter, "Upcoming sessions only", per-session notes disclosure, selected-day `.ics` export (<= 100). All times in explicit IST.
- Attendance: shows a percentage per month/course with the college threshold, a recovery estimate and a per-course overview (legacy learner page has none, the threshold lives only in the course tab); real statuses Late / Excused / Medical in addition to Present / Absent / Not marked / Scheduled; status/order filters, CSV export; month-aware URL state with recovery notices; a monthly attendance calendar page. Percentage uses marked sessions only (`Not marked` and `Scheduled` never count as Present), same intent as legacy LRN-AT-01.
- Aliases `/learn/assignments` and `/learn/quizzes` redirect to the legacy-named routes.
