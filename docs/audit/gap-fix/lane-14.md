## Legacy mapping contract and unresolved gates

Course active=true/false -> ACTIVE/ARCHIVED, enabled -> independent `courses.enabled`, is_deleted -> `deleted_at` set/null. A learner must pass all three filters, plus offering and role scope. Nested legacy contents JSON is retained in `legacy_metadata` without changing vNext flattened display fields. Legacy int course/parent/department IDs resolve through college-scoped `legacy_id_map` before UUID writes; no blind cast.

Lesson independent truth table (active,enabled,deleted -> status,visible,deleted_at): T/T/F -> ACTIVE/T/null; T/F/F -> ACTIVE/F/null; F/T/F -> ARCHIVED/T/null; F/F/F -> ARCHIVED/F/null. With deleted=T, retain active/enabled independently but set deleted_at; readers must exclude regardless of status. Lesson numeric courseId resolves by tenant through course -> offering -> path; historical period and cohort must be explicit. Sequence Java long/auto max+1 is deliberately not changed from vNext integer validation 0..10000 until API/DB policy review, not silently truncated. New version columns do not provide CAS until the writer checks expectedVersion and increments it atomically.

Teaching legacy faculty/class/course/batch/semester/year maps through college_memberships, course_section_deliveries, course_offerings, sections, cohorts, academic_periods. Delivery grants authorize course content; section grants authorize section responsibilities. Legacy start_date/end_date are date-only while existing started_at/ended_at are instants. Active grant must check date bounds and serialize promotion. Schema column alone does not enforce future dates.

Discussion int lessonContentId/userId/discussionId -> college-scoped legacy_id_map -> lesson_contents UUID/college_memberships UUID/optional legacy_discussion_id. Snapshots are DB-trusted from users.display_name and learner roll/registration when available; faculty legacy unique ID requires explicit importer mapping. Legacy deleted -> deleted_at. Reply/attachment/resolution fields are historical nullable records, no live feature claim. DB guarding scope is not learner enrollment or teaching entitlement; lesson-content API still unimplemented.
