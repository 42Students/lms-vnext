## Remaining release-sensitive differences / dependencies

- **Source parity is not customer acceptance:** legacy route mapping, label inventory and authored assertions do not certify actual user flows. Owner legacy login and final vNext browser walk are required.
- **Private file behavior:** storage signed-link read grants and object scanner need live verification; never route VIDEO through generic resource file downloads.
- **Certificates:** the audited legacy surface is a user-entered **profile certification**, not evidence that legacy awards a separate course-completion certificate.
- **Deep risk:** stale authenticated contexts, section changes, historical enrollments, back/forward quiz submissions and two simultaneous user sessions need real database and browser checks after the owner lifts the no-CI instruction.
