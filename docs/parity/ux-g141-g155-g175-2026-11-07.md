## UX-G141 — College study-group actions and import preview

Scope:
- `src/components/groups/college-group-actions.tsx`
- `src/components/groups/college-group-import-preview.tsx`
- `src/components/groups/college-study-member-actions.tsx`

Changes:
- Group create/edit/status actions now guard against synchronous double-submits with an in-flight ref, in addition to pending UI.
- Membership ID entry now validates the canonical five-field UUID structure before review.
- Review dialogs clear stale errors on fresh actions and display failures *inside* the open confirmation modal.
- Selecting a new CSV immediately invalidates the old CSV and preview, including oversized/unreadable uploads. Superseded asynchronous file reads can no longer change the reading indicator or restore stale content.
- Manual-ID import errors are shown at the manual action rather than being presented as unrelated CSV failures.
- Preview rows use human-readable validation reasons; the server rechecks actual capacity and membership eligibility when writing.

Relevant source commits: `ed0764d9c2203d46b1f96f09f8127b86488b6d58`, `22a000c3a89292a51ca2a39e6c205004ce4e6a10`, `a0cde77e196c0acb087eea6b17198560121b331f`.

## UX-G175 — Group CSV preview/export model and service

Scope:
- `src/modules/groups/college-group-csv-preview-model.ts`
- `src/modules/groups/college-group-csv-preview-service.ts`

Changes:
- Reject malformed quoted fields such as `"alice@example.com"oops` rather than silently importing a changed value.
- Preserve empty final quoted fields so validation can report the invalid email instead of dropping its row.
- Distinguish `GROUP_NOT_ACTIVE` from `CAPACITY_FULL` in dry-run preview; labels tell operators what to fix.
- Maintain the existing single-email-column constraint, 2,000-row limit, 512 KiB limit, same-college authorization, capacity rules, and formula-neutralized error export.

Relevant source commits: `eb61424bac1fe170c19ae4dfda5917a691c47945`, `43e6fc6c910b1e14fc69d07a3a08471628acb80e`, `55553e781e8ec132b61fbd96a2335b0816e9f19a`.
