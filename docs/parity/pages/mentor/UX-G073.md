## User-visible fixes
1. Member authorization now precedes invalid-filter display on all five routes. Invalid links cannot bypass role gating to see the recovery screen.
2. Malformed query links show clear non-destructive recovery copy and a route-specific **Clear filters** link; no failed read is presented as an empty report.
3. Delivery review queue and decision history distinguish an empty filtered result from a genuinely empty unfiltered state. The action becomes **Clear filters** when useful, or **Projects/Pending reviews** without filters.
4. Duplicate report query values are treated as invalid instead of silently choosing the first one.
