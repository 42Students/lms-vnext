## Implemented UX improvements
1. Notification history validates ACTIVE Learner membership before parsing a malformed cursor; instead of a dead-end 404, the authorized user gets an explicit no-records-loaded warning and a **View newest history** link.
2. The legacy `/learn/placements` bookmark now authorizes Learner membership before redirecting to My Placements; cross-role requests go safely to the Dashboard.
3. Profile completion checklist validates the selection before loading private profile details. Invalid selectors show **Show all sections** rather than a post-load 404.
4. Private **Who has my data** pagination no longer silently converts malformed, duplicated, or unknown URL selectors into page 1. The existing own-profile authorization runs first, then bad links offer an explicit safe reset without querying private sharing records.
5. Academic record, profile, notification and checklist loading/error components were inspected and retained where they already supplied honest, recoverable states. No consent or profile view is invented.
