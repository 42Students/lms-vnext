# UX-G048 and UX-G122 — dashboard and tracker acceptance, 8 November 2026

The only authoritative status board is `docs/tracker.json#uxReview.groups`.

pages, not repository-wide parity, RLS certification or production rollout.

## G048 — Role-aware dashboard

- In-scope source: `src/app/(authenticated)/dashboard/{page,loading,error}.tsx`.
- The Super Admin no-college dashboard exposes platform operations without
  leaking college-scoped counts. When a college is selected, the normal
  existing data-service, permission and scope policy determines visible tiles.
- Responsive metric cards, College Admin touch targets, dashboard-shaped
  loading skeleton and a safe route-specific error recovery were inspected.
- The live seeded browser test verifies the **unscoped named Super Admin**
  platform dashboard, actual navigation affordances and horizontal overflow
  at desktop (1280px) and mobile (390px). Anonymous HTTP/browser tests verify
  protected dashboard content is not exposed.

## G122 — tracker logs and reporter-owned issues

- In-scope source: `src/app/(authenticated)/tracker/logs/{page,loading,error}.tsx`;
  `src/app/(authenticated)/tracker/mine/{page,[publicId]/page}.tsx`.
- Private Cloud logs still require a **named, active, unscoped Super Admin**;
  denied attempts are audited, and the legacy shared-password route is not
  restored. Reporter list/details remain scoped to the named reporting actor.
- Improved log-loading title, recovery and accessible touch targets; own-reports
  retry, count/list label, safe detail states and optional screenshot handling.
- Browser checks verify named Super Admin recovery from an invalid log filter,
  learner log denial, learner own-report recovery, and anonymous absence of
  dashboard/tracker details at both desktop and mobile sizes.
