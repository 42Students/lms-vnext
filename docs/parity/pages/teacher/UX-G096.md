# UX-G096 — Faculty profile and assessment report navigation

Status: **DOING — scoped implementation committed, full acceptance pending.**

## Family and surfaces
- Faculty self-managed About/details: `/teacher/profile/details` including historic section bookmarks, private profile load failure and storage unavailable.
- Faculty teaching assignments: `/teacher/profile/teaching` including query invalid/duplicate/filtered/unfiltered empty/pagination and assigned-course deep links.
- Assignment report: `/teacher/report/assignment/[contentId]` and per-Section `/submissions` including invalid Section query, grading and publication filters, CSV scope and clear actions.
- Quiz report: `/teacher/report/quiz/[quizId]`, with distinct safe invalid-link recovery and authorized multi-Section selection.
- Existing route `loading.tsx` and `error.tsx` fallbacks remain in scope but unchanged; no new data writes or permissions added.

## Completed source changes
1. Active Faculty membership is now checked **before** legacy profile bookmark redirects and malformed self-profile teaching/submission filters. Duplicate profile section query values no longer silently pick one bookmark.
2. Teaching profile filters are strict about duplicate and unknown selectors; malformed links display an accurate no-data-loaded warning and route-specific reset.
3. Teaching empty states distinguish search-no-match from no registered current assignments; offer **Clear search** or **Teaching courses** navigation.
4. Invalid submission report query gives a safe context-preserving link to the authorized assignment report plus a fallback to All Assignments, without loading any learner rows.
5. Empty submission results provide a reset of grading, name search, publication and chronological filters, preserving the verified Section/assignment identifiers. Existing private-grade export scope and authenticated service boundaries unchanged.
