# UX-G157 — TPO component usability and recovery

**Tracking:** `docs/tracker.json#uxReview.groups[UX-G157]`. The source registry contains 15 group-owned components. This focused pass covers changes to three and review of existing related workflows; unchanged components are not individually certified by browser tests.

## Changes
- `TpoCompanyTeamComposer`: the editor is remounted by company and actor identity so an unsent private company thread draft cannot be exposed in the editor for another company's conversation. Idempotency token and session-scoped draft preservation remain keyed to actor+company.
- `TpoBlockedDatesEditor`: explicit live IST range validation and a 90-day maximum explanation, keyboard/screen-reader help association on dates, honest invalid-range status. Existing same-origin, versioned removal guards are untouched.
- `TpoBatchStudentSavedViews`: prevents selecting the sixth pinned view, locks the saved-view editor during in-flight mutation, prevents misleading empty states while loading/failing, and displays deletion errors within its confirmation dialog. Existing per-user/per-batch scope stays in backend.

## Acceptance
`tests/unit/ux-g157-interactions.test.ts` asserts request and privacy guards. `tests/e2e/ux-g157.spec.ts` uses genuine components with synthetic records, development-only fixture and mocked same-origin API calls on desktop 1280×800 and mobile 390×844; covers cross-company draft isolation/recovery, blocked-range errors, sixth-pin prevention, delete failure recovery and campaign delivery unavailability. Dedicated CI includes exact SHA, scoped ESLint, Vitest, Chromium and TypeScript, plus screenshots in Actions artifacts.
