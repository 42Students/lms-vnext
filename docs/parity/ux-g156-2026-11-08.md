# UX-G156 — TPO recruiter and batch interactive components

**Canonical group:** `docs/tracker.json#uxReview.groups[UX-G156]`, which owns 15 TPO component files. This batch targets three evidence-backed defects. Other group components are source-reviewed; they are not individually browser-certified by these tests.

## Changes
- Batch invitation and reminder no longer fabricate recipient counts from an initial eligible/invitable snapshot or a missing field. Only a verified non-negative integer server receipt may be displayed; on malformed success responses the UI tells the officer the operation may have committed and requires a refresh before any retry. This preserves truthful in-app-only communication.
- Class decision confirmation retains same-origin POST, version checking, and presents conflict errors inside the active alert dialog. No student-level override is touched.
- Audit saved views rejects malformed/partial API responses, avoiding crashes or rendering rows with invalid filters. It shows exactly one active error, in the delete dialog when that dialog is open or in the page otherwise, instead of duplicating it. It preserves the account/college-private API and existing stale/retry behavior.
