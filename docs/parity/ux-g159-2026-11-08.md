## Scope and changes

This group holds 15 interactive TPO component source files: recruiter reply, student spreadsheet/edit/bulk/preparation flows, and team threads, asks, away, and message actions. The accepted changes in this pass target specific issues in three components; remaining controls were source-reviewed and remain unchanged, without an independently evidenced end-to-end certification.

- **Away status:** Rejects malformed or past India Standard Time dates before calling the server, clears a successful date draft, and provides explicit stale-version/permission recovery messages while keeping existing same-origin `expectedUntil` request semantics.
- **Conversation rename:** On stale-version 409/permission 403, keeps the entered topic and provides actionable feedback. Prevents closing the rename entrypoint while a save is active. Retains the `expectedTopic` server concurrency guard.
- **Team message edit/delete:** Same-origin, hash-guarded edits and deletes explain 409/403 conflict without discarding the unsaved edit or silently closing the confirmation dialog. Other recipient and permissions rules are unchanged.
