# DB08-C external offer tables — official migration proposal (not registered)

**Owner:** database migration orchestrator. The Drizzle definitions currently exist at `src/db/schema/placement-external.ts`, but the only SQL is `scripts/sql/db08-external-offers-staging.sql`; **do not label these tables deployed**. Proposed migration must also cover `placement_external_offer_events` and `placement_saved_jobs` because their runtime services depend on them.

## Tables and integrity contracts

1. `placement_external_offers`: `id uuid PK DEFAULT gen_random_uuid()`; `college_id uuid NOT NULL REFERENCES colleges(id) ON DELETE RESTRICT`; `membership_id uuid NOT NULL REFERENCES college_memberships(id) ON DELETE RESTRICT`; `company_name varchar(200) NOT NULL`; `ctc_lpa numeric(10,2)`; `private_letter_object_path text`; `submitted_by_user_id uuid NOT NULL REFERENCES users(id) ON DELETE RESTRICT`; `status varchar(24) NOT NULL DEFAULT 'SUBMITTED'`; reviewer ID/timestamp, reason, revoker ID/timestamp, reason, created/updated timestamps. Check nonempty company, nonnegative CTC, status in SUBMITTED/VERIFIED/REJECTED/REVOKED, review ID/time required exactly for verified/rejected/revoked, revoke ID/time/reason required only for revoked. Index `(college_id,status)` and `(membership_id,status)`.
2. `placement_external_offer_events`: `id uuid PK`; `offer_id uuid NOT NULL REFERENCES placement_external_offers(id) ON DELETE RESTRICT`, nullable prior status, required next status and `actor_user_id REFERENCES users(id) ON DELETE RESTRICT`, reason and occurred timestamp. Enforce known next statuses; index `(offer_id, occurred_at)`. Immutable audit history (trigger rejects UPDATE/DELETE).
3. `placement_saved_jobs`: `id uuid PK`, `college_id REFERENCES colleges(id)`, `membership_id REFERENCES college_memberships(id)`, `job_id REFERENCES placement_jobs(id)`, all NOT NULL, saved timestamp. Unique `(membership_id,job_id)`, index `(college_id,membership_id)`.

**Mandatory cross-row protections:** In triggers or equivalent DB-enforced constraints, prove external offer college matches the learner membership's college; submitted_by must match membership.user_id and learner role; offer identity, CTC, and company immutable after submission; only SUBMITTED→VERIFIED/REJECTED and VERIFIED→REVOKED. Saved job's college must match BOTH the membership and job. Verification/revocation actor must have the correct tenant TPO/admin authorization (require DB-authoritative reviewer proof). Preserve private letter object ownership and audit event on each transition. Register via numbered migration, journal and snapshot in the single-writer lane, with real Postgres negative/FK/concurrency tests and replay before enabling source writes.

**Runtime interim behavior:** `held-offer-facts-service.ts` checks the table's presence before reading it. An absent table yields only actual internal held offers, not synthetic external holds. This avoids relation-not-found crashes but is **not full P-S1-05 correctness**: external verified holds cannot be enforced until DB08-C registration. Do not report P-S1-05 DONE or enable external-offer write routes as fully available before registration. Existing staging SQL is the implementation reference, **not** a deployed migration.
